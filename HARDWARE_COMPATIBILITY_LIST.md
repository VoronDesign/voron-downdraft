# Hardware Compatibility List for DownDraft

## Hotend Support

This is a non-comprehensive list of hotends and which Front Mount to use for HE
fan placement, the text in brackets is the name on the Hotend Mount:

#### Front Mount High:

- Goliath / CHC XL (GOLIATH)

- Dragon UHF (D.UHF)

- Rapido UHF / Rapido X (D.UHF)

- Rapido X (RAP X)

- Tricorn Air Long (TRI.L)

- Dragon Ace + MZE (D.ACM)

#### Front Mount Middle:

- Dragon Ace (D.ACE)

- Dragon Volcano (RAPID)

- Rapido HF (RAPID)

- Tricorn Air Short (TRI.S)

- Revo Voron Volcano (R.VOL)

#### Front Mount Low:

- Dragon SF/HF (DRGN)

- Chube Compact (CHBC)

- TZ-V6 v2 with V6 nozzle (TZV6.2)

- Revo Voron (REVO)

## Extruder Support

#### Native:

- Orbiter v2 mount pattern

#### Using Alternative_Extruder_Spacer:

- LGX Lite mount pattern

- Sherpa Mini mount pattern

## Hotend 2510 Axial Fan Support

- GDStime 2510

- Vindr 2510

- Delta 2510

## Part Cooling Fan Support

Always select the highest rpm available. This is particularly important with GDStime fans that come in different speeds.

#### 5015 Blower Fans:

- GDStime 5015 (8500 rpm)

- Delta BFB0524HH 5015

- R3:men 5015

- Vindr Berkserker 5015 (Does not use the spring mount part, front cable tabs need to be removed)

- Mechatronics 5015 (very tight fit and may damage mount)

#### 4010 Blower Fans:

- GDStime 4010

- Vindr 4010

- Honeybadger 4010

- Delta 4010
