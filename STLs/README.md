# Downdraft Toolhead

### Common_Parts

Contains parts to construct the toolhead that are shared between the 4010 and 5015.

### Dual_4010

Contains specific parts for the 4010 dual part cooling fan toolhead.

### Dual_5015

Contains specific parts for the 5015 dual part cooling fan toolhead.

### Extras

Contains value added parts to expand the toolhead. These are provided as-is as they are not essential to the build.

### Filename Nomenclature

| Filename    | Note                                    |
| ----------- | --------------------------------------- |
| \*.stl      | Base color                              |
| [a]\_\*.stl | Accent color                            |
| [o]\_\*.stl | Opaque (light doesn't penetrate)        |
| [c]\_\*.stl | Clear/Translucent (light can penetrate) |
