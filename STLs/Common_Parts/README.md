# Downdraft Toolhead

### Hotend_Mounts

Contains mounts for a variety of hotends. A blank is provided for users to create their own mounts if one is not already provided.

### LED_Jigs

Contains parts to help soldering the Logo and Nozzle LED wires to an appropriate length.

### LED_Mounts

Contains parts to attach Logo and Nozzle LED's to the toolhead

### PCB_And_Chain_Mounts

Contains mounts for 2 or 3 hole chains to mount to the toolhead.

Contains mounts for a variety of CAN/USB and direct cable toolhead PCB boards.

### Alternative_Extruder_Spacer.stl

Used to mount extruders to the toolhead that do not use the integrated Orbiter v2.* mount pattern. Sherpa Mini and LGX Lite mount patterned extruders can be used with this part.

### Bowden_Mount_Collet.stl

For use with a remote extruder with an 4mm collet to retain the PTFE tube.

### Bowden_Mount_ECAS.stl

For use with a remote extruder with an ECAS04 to retain the PTFE tube.
