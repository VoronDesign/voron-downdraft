# Downdraft Toolhead

### 2hole_Chain_SB_NH_36_PCB_Mount.stl

### 3hole_Chain_SB_NH_36_PCB_Mount.stl

These are generic cable chain mounts. Additionally, they can be used to support single board Stealthburner and Afterburner PCB boards, as well as 36mm PCB boards.

### Other Parts

These parts are to mount 36mm PCB boards to the toolhead using 2 or 3mm cable chains. They are extruder specific with a range of Orbiter v2.* mounting pattern extruders provided. Each contains a 3rd contact point on the extruder to improve stability.
