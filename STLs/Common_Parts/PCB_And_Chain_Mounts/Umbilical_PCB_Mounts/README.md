# Downdraft Toolhead

### PUG_Generic

Contains mounts that support using a 36mm PCB board or 2 part Stealthburner PCB board together with the PUG umbilical system and most extruders.

### PUG_Integrated

Contains mounts that support using a 36mm PCB board or 2 part Stealthburner PCB board together with the PUG umbilical system and specific Orbiter v2.* mount pattern extruders with an additional mount point on the extruder for stability.

### xSB_PCB_Mount.stl

This mount is to attach the daughter board of a 2 part Stealthburner PCB board.

### Umbilical_PCB36_Mount.stl

This is a generic traditional strain relief for umbilical configurations for both 36mm PCB boards and 2 part Stealthburner PCB boards.

### Other Parts

These mounts provide a traditional strain relief for umbilical configurations for both 36mm PCB boards and 2 part Stealthburner PCB boards. The parts are specific to Orbiter v2.* mount pattern extruders with an additional mount point on the extruder for stability.
