# Downdraft Toolhead

### [c]_LED_Diffuser.stl

This part is to be printed in a transparent or translucent material. It is the same diffuser as used in the Stealthburner toolhead.

Suggested filaments:

- "Natural" ABS - this is an off-white colour that diffuses the LED light

- Clear PETG - provides a little diffusion depending on how it is printed

### [o]_LED_Diffuser_Mask.stl

This part is used to retain the LED_Diffuser and should be printed in an opaque filament, e.g. black ABS/ASA to prevent light leakage.

### [o]_Neopixel_Carrier.stl

This part is used to retain a Neopixel LED and should be printed in an opaque filament, e.g. black ABS/ASA to prevent light leakage.

### [o]_BARF_LED_Carrier.stl

This part is used to retain a BARF LED and should be printed in an opaque filament, e.g. black ABS/ASA to prevent light leakage.
