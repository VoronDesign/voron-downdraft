# Downdraft Toolhead

## Extras

The parts found within this directory tree are provided to expand support for additional hardware and features. These are provided as-is as they are not essential to the build.

### Roto_Vitamins

Contains a replacement front part to the Roto Vitamins extruder that is compact and supports to standard Orbiter v2.* extruder mount pattern.

### WWG2

Contains replacement front parts for the WWG2 extruder that extends the height of the mounting holes to allow standard length screws to be used for mounting.

### Crossbow_Cutter_Mount.stl

This mount supports the Crossbow Cutter provided by DW Tas. It sits between the toolhead and the extruder. Using it will prevent the use of the extruder specific PCB mounts as the 3rd mount point on the extruder will be at a higher point.

### E3D_PZ_PCB_Mount.stl

This part allows the PZ PCB board to be mounted to the side of the a 36mm PCB board mount. It will not work with 2 part Stealthburner PCB mounted boards as it uses the same mount location.

### Generic_ADXL_Mount.stl

This part allows a generic ADXL board to be mounted to the side of the a 36mm PCB board mount. It will not work with 2 part Stealthburner PCB mounted boards as it uses the same mount location.

### XOL-CNC-Carriage-CW2_square_nut_holder.stl

This part allows the toolhead to be mounted to the Xol carriage CNC mount provided by DW Tas.
